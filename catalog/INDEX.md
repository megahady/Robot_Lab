# Awesome MuJoCo Robots [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of **68 ready-to-run robots** for [MuJoCo](https://mujoco.org), with real-time physics running in your browser.

Models come from [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie) and are vendored in [`catalog/`](.). Each directory is self-contained: meshes in `assets/`, the primary model file, plus its own `README.md` and `LICENSE`.

**Click any picture to run that robot in the online MuJoCo viewer** — physics, meshes and colliders compiled from this repository, streamed straight into your browser.

## Adding a Robot

Drop a Menagerie-style folder into `catalog/` with its `assets/`, model XML, `README.md` and `LICENSE`, then regenerate the index and the viewer model list:

```bash
python robot_studio/catalog_index.py
```

Then add the robot to its category above. The gallery images are rendered by `catalog_index.py` and named `<robot>__<image>.png`.
