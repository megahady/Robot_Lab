# Catalog

70 models from [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie), vendored here as self-contained directories: `assets/` (meshes and textures), a scene file, a per-robot `README.md` and `LICENSE`.

The browsable catalog — thumbnails that open in an in-browser MuJoCo viewer, grouped by category with DoF counts and licenses — lives in the [repository README](../README.md#models).
